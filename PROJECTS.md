### About This List

This page lists open-source projects that have adopted the **Selective Freedom License (SFL) v1.0**. By using SFL, these projects demonstrate their commitment to open-source principles while exercising their right to exclude specific entities.

### How to Add Your Project

We welcome all projects using SFL to be listed here! To add your project:

1. **Fork this repository**
2. **Edit this file** (`PROJECTS.md`)
3. **Add your project** following the format below
4. **Submit a pull request**

### Project List Format

Please add your project in the following format:

```markdown
#### [Project Name](https://github.com/username/project)
- **Description**: Brief description of what your project does
- **Language**: Primary programming language(s)
- **License Adopted**: YYYY-MM-DD
- **Maintainer**: [@username](https://github.com/username)
```
